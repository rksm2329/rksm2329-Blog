堆是一种支持动态快速查询最值的数据结构，支持以下操作：

- 高效插入元素。
- 高效查询、删除最值。
- 高效修改指定元素、删除指定元素。

## 性质

平时说的堆通常就指**二叉堆**,二叉堆是一种完全二叉树,它具有下面的性质:

> 如果堆为**小根堆**
>
> - 父节点的值不大于两个儿子的值
>
> 如果堆为**大根堆**
>
> - 父结点的值不小于两个儿子的值

堆的根结点⼜被称为堆顶，⼩根堆的堆顶元素是堆中最⼩的元素，大根堆就反着来。

## 存储

因为它是完全二叉树，所以可以直接用数组存储：

```cpp
int heap[MAXN], len;
```

## 基本操作

一个容器，最先要考虑的是**增、删、改、查**四个操作。

当对堆进行上面的操作的时候，可能会破坏堆的性质，也可能让堆不是完全二叉树，**要考虑如何处理**。

可以用两种操作来维护堆的性质：上浮、下沉，仅适用于小根堆，大根堆两个操作相反。

### 上浮

当修改了堆中的某一个元素的时候，如果这个元素变小了：

- 如果这个结点有父亲结点，并且值比父亲更小，那么交换当前结点与父亲节点的值，继续执行操作。
- 否则，停止操作。

#### 实现

```cpp
void up(int x) { // 上浮
  for (int i = x, j = i / 2; j >= 1 && heap[i] < heap[j]; i = j, j = i / 2) {
    swap(heap[i], heap[j]);
  }
}
```

### 下沉

当修改了堆中的某个元素的时候，如果这个元素变大了：

- 如果这个结点有儿子结点，并且值比**较小的儿子**更大，那么交换当前结点与较小的儿子结点的值，继续执行操作

#### 实现

```cpp
int son(int x) { // 返回较小的儿子
  int i = x * 2, j = x * 2 + 1;
  return i + (j <= n && heap[i] > heap[j]);
}

void down(int x) { // 下沉
  for (int i = x, j = son(i); j <= n && heap[i] > heap[j]; i = j, j = son(i)) {
    swap(heap[i], heap[j]);
  }
}
```

### 查询最值

```cpp
int top() { // 查询最值
  return heap[1]; // 小根堆则为最小值，大根堆则为最大值
}
```

### 插入元素

可以在堆的尾部增加一个结点，保证堆仍然是一棵完全二叉树，然后上浮。

```cpp
void push(int x) {
  heap[++n] = x;
  up(n);
}
```

### 删除最值

如果直接删除堆顶，会使堆分裂为两个堆，⽽删除堆尾元素不需要维护。可以将堆顶和堆尾元素进⾏交换，然后删除堆尾元素，保证堆仍然是⼀棵完全⼆叉树。 如果交换后的堆顶不满⾜堆的性质，就下沉。

```cpp
void pop() {
  swap(heap[1], heap[n--]);
  down(1);
}
```

## `priority_queue`

`priority_queue`，即优先队列，就是 C++ 已经弄好的堆，比赛时常用这个容器代替堆。

### 头文件

```cpp
#include <queue>
```

### 定义

```cpp
#include <queue>
#include <vector>
#include <functional>

// 需要 3 个参数：Typename数据类型名，Container底层容器，Compare比较器
// 底层容器和比较器为可选参数
// 不指定底层容器和比较器时，默认为 vector<Typename> 和 less<Typename>（也就是大根堆）
priority_queue<Typename, [Container], [Compare])> q;

// 大根堆
priority_queue<int> q1;
// 定义了一个类型为 int，底层容器为 vector<int>，比较器为 less<int> 的优先队列

// 小根堆
priority_queue<int, vector<int>, greater<int>> q2;
// 定义了一个类型为 int，底层容器为 vector<int>，比较器为 greater<int> 的优先队列
// 需要引入头文件 <functional>

// less 中文为较小的，但实际上是大数靠前的比较器，greater 为较大的，实际上是小数靠前的比较器。
```

### 成员函数

$N$ 为堆内元素个数。

- `top()` 访问堆顶，$O(1)$
- `empty()` 判断是否为空，$O(1)$
- `size()` 元素个数，$O(1)$
- `push(x)` 插入 $x$，$O(\log N)$
- `pop()` 弹出堆顶，$O(\log N)$
- 注意：没有 `clear()` 函数，清空需要不断 `pop()`

### 自定义比较器

对于结构体类型，我们需要定义其⽐较规则才能⽤优先队列维护该类型元素。

```cpp
struct Node {
	int x, id;
};
```

#### 方法 1：定义比较器函数对象

```cpp
struct cmp {
	bool operator()(const Node &i, const Node &j) const { // 函数尾的 const 表示该函数不能对所在类的成员进⾏修改
		return i.x < j.x;
	}
};

priority_queue<Node, vector<Node>, cmp> pq; // 定义了⼀个 x 为关键字的⼤根堆
```

#### 方法 2：重载运算符

```cpp
bool operator<(const Node &i, const Node &j) {
	return i.x > j.x;
}

priority_queue<Node> pq; // 定义了⼀个 x 为关键字的⼩根堆
```

```cpp
struct Node {
  int x, id;
  bool operator < (const Node &i) const {
	  return x > i.x;
  }
};

priority_queue<Node> pq; // 定义了⼀个 x 为关键字的⼩根堆
```

#### 方法 3：使⽤ lambda 表达式（需要 C++11 及以上标准）

```cpp
auto cmp = [](const Node &i, const Node &j) {
	return i.x < j.x;
};
priority_queue<Node, vector<Node>, decltype(cmp)) pq; // x 为关键字的⼤根堆
```

### 例子

```cpp
struct cmp{
  bool operator()(int i, int j) {
    return i > j;
  }
};

priority_queue<int> pq1; // ⼤根堆
priority_queue<int, vector<int>, cmp> pq2; // 小根堆
pq1.push(1);
pq1.push(2);
cout << pq1.top() << '\n'; // 2
pq1.pop();
cout << pq1.top() << '\n'; // 1
pq2.push(1);
pq2.push(2);
cout << pq2.top() << '\n'; // 1
pq2.pop();
cout << pq2.top() << '\n'; // 2
```

#### 结构体

```cpp
struct Student {
	int a, b, c; // 三科的成绩
};

struct cmp {
  bool operator()(const Student &i, const Student &j) {
    if (i.a != j.a) {
      return i.a < j.a;
    }
    if (i.b != j.b) {
      return i.b < j.b;
    }
    return i.c < j.c;
  }
};

priority_queue<Student, vector<Student>, cmp> pq; // 按语数外从⾼到低排

int main() {
  ios::sync_with_stdio(0);
  cin.tie(0), cout.tie(0);
  pq.push({100, 100, 90});
  pq.push({100, 100, 100});
  pq.push({100, 90, 100});
  pq.push({90, 100, 100});
  while (!pq.empty()) {
    Student x = pq.top();
    pq.pop();
    cout << x.a << ' ' << x.b << ' ' << x.c << '\n';
  }
  return 0;
}
```

## 例题

### [P1090 [NOIP2004 提高组] 合并果子](https://www.luogu.com.cn/problem/P1090)

贪⼼，每次选出数⽬最⼩的两堆进⾏合并即可。暴⼒模拟是 $O(n^2)$，可以⽤优先队列优化⾄ $O(n \log n)$。如果把合并过程建树，那么题⽬所要求的的答案就是 $\sum \limits_{i = 1}^{n} a_id_i$，$a_i$ 为数⽬，$d_i$ 为 在树中的深度，显然 $d_i$ ⼤的叶⼦结点 $a_i$ ⼩的两堆进⾏合并。
尽可能⼩，因此每次选出数⽬最⼩的两堆进⾏合并。

```cpp
#include <bits/stdc++.h>

using namespace std;

int n, x;
priority_queue<int, vector<int>, greater<int>> pq;

int main() {
  cin >> n;
  for (int i = 1; i <= n; i++) {
    cin >> x;
    pq.push(x);
  }
  int ans = 0;
  while (pq.size() != 1) {
    int x = pq.top();
    pq.pop();
    int y = pq.top();
    pq.pop();
    ans += x + y;
    pq.push(x + y);
  }
  cout << ans;
  return 0;
}
```

### [P1631 序列合并](https://www.luogu.com.cn/problem/P1631)

堆优化。

如果暴⼒记录所有和，再加上排序，时间复杂度⾼达 $O(n^2 \log n)$。

我们可以先对 $n$ 个和进⾏分组：

- 第⼀组：$a_1 + b_1, a_1 + b_2, a_1 + b_3,\dots ,a_1 + b_n$
- 第⼆组：$a_2 + b_1, a_2 + b_2, a_2 + b_3,\dots ,a_2 + b_n$
- 第 $n$ 组：$a_n + b_1, a_n + b_2, a_n + b_3,\dots ,a_n + b_n$

由于题⽬给出的序列 $a$ 和 $b$ 都是单调不减的，我们发现每组内的 $n$ 个和也都是单调不减的。可以暴⼒⽤ $n$ 个指针维护每⼀组的最⼩值，每次取⼀个最⼩值 $O(n)$，总时间 $O(n^2)$。

设计状态【和，和所属的组，和在所属组中是第⼏个】。⼀开始先将每组的最⼩和的状态存储在堆中。每次取出堆中的最⼩和后，将该组的后⼀个和压⼊到堆中。执⾏ 次这样的操作，最⼩的 $n$ 个和就得到了。总时间 $O(n \log n)$。
为了⽅便实现，使⽤结构体表示状态，使⽤ `priority_queue` 代替堆。

```cpp
#include <bits/stdc++.h>

using namespace std;

const int MAXN = 1e5 + 10;

struct node {
  int sum, i, j;
  bool operator<(const node &j) const {
    return sum > j.sum;
  }
};

int n, a[MAXN], b[MAXN];
priority_queue<node> pq;

int main() {
  cin >> n;
  for (int i = 1; i <= n; i++) {
    cin >> a[i];
  }
  for (int i = 1; i <= n; i++) {
    cin >> b[i];
  }
  for (int i = 1; i <= n; i++) {
    pq.push({a[i] + b[1], i, 1});
  }
  for (int i = 1; i <= n; i++) {
    cout << pq.top().sum << ' ';
    node now = pq.top();
    pq.pop();
    pq.push({a[now.i] + b[now.j + 1], now.i, now.j + 1});
  }
  return 0;
}
```

### [P4053 [JSOI2007] 建筑抢修](https://www.luogu.com.cn/problem/P4053)

这个题状态有两个属性【修理时⻓，截⽌时刻】，可以先对截⽌时刻排序（相当于是给所有建筑定义了⼀个优先级，截⽌时间越早的肯定越要先完成）。

按排序后的顺序模拟修理建筑，并记录修理总时⻓。反例如下：

```
3
100 100
2 101
3 102
按此贪⼼只能修第 1 个建筑，实际能修第 2、3 个 建筑
```

如果总时⻓不超过当前建筑的截⽌时刻，那就把当前建筑加⼊到修理计划当中；

否则，说明必然有⼀个建筑是不能修理的，为了让后⾯的建筑修理有更多的时间，我们应该不去修理前⾯所有建筑中时⻓最⻓的那⼀个。

可以⽤堆来存储所有修理建筑的时⻓，加⼊修理计划——堆中插⼊元素，移除时⻓最⻓的建筑——删除堆中最⼤值。

```cpp
#include <bits/stdc++.h>

using namespace std;

const int MAXN = 15e4 + 10;

struct node {
  int t1, t2;
} a[MAXN];

int n;
priority_queue<int> pq;

bool cmp(const node &i, const node &j) {
  return i.t2 < j.t2;
}

int main() {
  cin >> n;
  for (int i = 1; i <= n; i++) {
    cin >> a[i].t1 >> a[i].t2;
  }
  sort(a + 1, a + n + 1, cmp);
  long long sum = 0, ans = 0;
  for (int i = 1; i <= n; i++) {
    sum += a[i].t1;
    pq.push(a[i].t1);
    if (sum <= a[i].t2) {
      ans++;
    } else {
      sum -= pq.top();
      pq.pop();
    }
  }
  cout << ans;
  return 0;
}
```
